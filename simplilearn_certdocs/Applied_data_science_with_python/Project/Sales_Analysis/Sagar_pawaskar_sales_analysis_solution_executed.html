# Load and clean
raw = pd.read_csv(DATA_PATH)
df = raw.copy()
# Strip stray spaces in categorical columns
df['State'] = df['State'].str.strip()
df['Group'] = df['Group'].str.strip()
df['Time'] = df['Time'].str.strip()
# Parse dates and create time features
df['Date'] = pd.to_datetime(df['Date'].str.strip(), format="%d-%b-%Y")
df['Month'] = df['Date'].dt.to_period('M').dt.to_timestamp()
df['Week'] = df['Date'].dt.to_period('W').dt.start_time
df['Quarter'] = df['Date'].dt.to_period('Q').dt.start_time
# Order time-of-day categories
TIME_ORDER = ["Morning", "Afternoon", "Evening"]
df['Time'] = pd.Categorical(df['Time'], categories=TIME_ORDER, ordered=True)

print(df.head())
print("\nRows:", len(df))
print("\nMissing values by column:\n", df.isna().sum())

Submission Write-up (Summary)¶
    

  • Goal: Analyze Q4 2020 Australia apparel sales to guide Sales & Marketing on where to invest, which demographics to target, and when to run offers.
    • 

  • Data: AusApparalSales4thQrt2020.csv (7,560 rows; fields: Date, Time, State, Group, Unit, Sales). No missing/negative values.
    • 

  • Method: Cleaned whitespace; parsed dates; engineered Month/Week/Quarter; min-max normalized Unit & Sales; GroupBy aggregations; visualized with Seaborn/Matplotlib (state revenue & units, group heatmap, time-of-day bars/heatmap, daily/weekly/monthly/quarterly trends, box plot, distribution).
    • 

  • Key findings:
      

    • Top revenue states: VIC, NSW, SA; lowest: WA, NT, TAS.
      • 

    • Time-of-day: Morning/Afternoon slightly lead; Evening close behind.
      • 

    • Demographics: All groups contribute similarly; VIC dominates every group.
      • 

    

    • 

  • Recommendations:
      

    • Double down on VIC/NSW high-value segments; premium/loyalty offers.
      • 

    • Target WA/NT/TAS with localized promos and assortments tuned to their leading group (see heatmap).
      • 

    • Staff/ads heavier in Morning/Afternoon; use off-peak for loyalty nudges.
      • 

    • Maintain monthly dashboards; monitor weekly for campaign effects.
      • 

    

    • 

  • Tools & libs: Python 3.9, pandas, seaborn, matplotlib, scikit-learn (MinMaxScaler), nbconvert.
    • 























Findings & Recommendations¶
    

  • Top revenue states: Use the bar chart to confirm leaders; focus retention and premium offers there.
    • 

  • Low revenue states: Bottom states warrant localized promos, influencer tie-ups, or inventory refresh. Consider pilot campaigns tailored to the dominant demographic group in each low-performing state (see heatmap).
    • 

  • Peak times: Highest volumes occur where the time-of-day bars peak; staff and ads should concentrate here. Off-peak windows are good for loyalty nudges.
    • 

  • Demographics: Heatmap shows which groups drive each state; align assortments and messaging accordingly.
    • 

  • Visualization choice: Seaborn is used for concise statistical plots (distribution, boxplot) and consistent styling; Matplotlib is leveraged underneath for flexibility in axes formatting.
